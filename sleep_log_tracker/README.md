# Sleep Log Tracker

ET574 section M, Project 1.

The repeating menu and startup guidance are implemented. Entry collection validates real dates, hours from 0 through 24, quality from 1 through 5 and optional notes. Closing entry input cancels the incomplete session without appending fields. Shared lists stay aligned; reports remain placeholders. Data exists only during the current run.
Open sleep_log_tracker/main.py and choose Run Python File in Terminal.
Python 3 is required. No third-party packages are needed.
